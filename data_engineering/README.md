# Data Engineering Interview Prep

| Resource | Description |
|----------|-------------|
| [SQL Practice Suite](sql_practice/README.md) | 50 medium/hard DE SQL problems on in-memory DuckDB, with a browser UI (`python3 app.py`) and a CLI runner |
